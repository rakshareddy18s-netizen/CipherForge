ABOUT THE PROJECT

A simple approach to stronger password security.

CipherForge was designed to help users create secure passwords without relying on predictable patterns or weak combinations. Passwords are generated locally using the browser's cryptographic functionality.

01

Privacy First

Passwords are generated locally inside the user's browser. No password information is stored, uploaded or transmitted.

02

Customizable

Users can choose password length and control whether uppercase letters, lowercase letters, numbers and symbols are included.

03

Security Focused

Password generation uses the browser's Web Crypto API to produce stronger random values instead of relying on basic randomization.
