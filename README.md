# CipherForge – Secure Password Generator

A secure, customizable, browser-based password generator developed using HTML, CSS, and JavaScript.

CipherForge helps users generate strong passwords using the browser's Web Crypto API, providing a simple and privacy-focused password generation experience.

## Features

* Generate strong and customizable passwords.
* Choose password lengths between 4 and 32 characters.
* Include uppercase letters, lowercase letters, numbers, and symbols.
* View password strength indicators.
* Copy generated passwords to the clipboard.
* Responsive and user-friendly interface.
* Browser-based password generation.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Web Crypto API

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Customize the password settings and click Generate Secure Password.
